# Workshop avatar asset

Source: Ready Player Me, Visage example `public/male.glb` at commit
`adf92f2c8abf0934e35bf8976904b0967b40ffff`.
https://github.com/readyplayerme/visage/blob/adf92f2c8abf0934e35bf8976904b0967b40ffff/public/male.glb

The repository license from the same revision is included as
`visage-LICENSE.txt`. Attribution: Copyright (c) 2023 Ready Player Me.

This local student prototype loads the GLB from its own public folder; it does
not call an avatar API or transmit account information. Added chair animation,
seated bone posing, cloth hood and glasses are implemented in
`src/lib/loginWorkshopAvatar.ts`. The source asset remains unmodified.
