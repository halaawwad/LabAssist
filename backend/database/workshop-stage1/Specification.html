Rules enforced by SQL

  • Only one non-disabled workshop manager account can exist.
  • Manager cannot have a student university number or account supervisor.
  • Only manager accounts can own workshop settings, availability and read state.
  • Temporary absence requires an end after the start; full-day absence has no time range.
  • One availability row per manager/day and one read record per notification key.
  • Profile photo must be a ready image owned by the manager.
  • Passwords are never seeded. Existing shared account rules accept Argon2id hashes, not plaintext.

No fixed absence threshold is introduced. Attendance calendars, repeated-absence policy, one-time alerts and edit windows belong to their later backend feature stage. Current UI demo fixtures remain separate from SQL data until integration.

Implementation boundary

No backend or live authentication was added. The roster view is not RLS or an API permission guard. Backend must authorize access, route notices to all linked supervisors and enforce editing rules. No inventory or previous-student Facebook offers were added to the manager role.
