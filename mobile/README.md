# LabAssist Mobile

React Native · TypeScript · Expo SDK 58

- `/native`: native student dashboard.
- `/native/student/*`, `/native/supervisor/*`, `/native/workshop/*`: role screens.
- `/native-preview`: phone-sized browser preview.
- `/`: original web preview.

```sh
npm ci
npm start
npm run typecheck
npm test
```

Screens currently use local sample data and device storage.
