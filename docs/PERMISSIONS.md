# LabAssist Permissions

## Student
Can:
- Work on own project.
- Manage assigned tasks.
- Use the 3D Lab.
- Create wiring connections.
- Manage project BOM according to permissions.
- Request workshop components.
- Submit reports.
- Report issues.
- Request meetings.

Cannot:
- Manage workshop inventory.
- Record official attendance.
- Approve own reports.
- Modify unrelated projects.

## Supervisor
Can:
- Access supervised projects.
- Monitor progress.
- Assign tasks.
- Review milestones.
- Review 3D circuits.
- Add feedback.
- Review reports.
- View attendance.
- Monitor issues and risks.

Cannot:
- Manage unrelated projects.
- Manage workshop inventory unless explicitly authorized.

## Workshop Manager
Can:
- Manage workshop inventory.
- Manage component sales.
- Process part requests.
- Record attendance.
- Manage workshop tables and spaces.
- Manage reservations.
- Add observations.
- Send supervisor alerts.
- Publish announcements.

Cannot:
- Approve academic milestones.
- Modify academic project progress.
- Review academic reports as a supervisor.

## Project Team Roles
Projects may contain:
- Leader
- Assistant
- Member

Permissions may vary according to the team role.
