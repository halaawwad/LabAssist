# LabAssist Goal

LabAssist is an intelligent platform for managing university hardware graduation projects from idea to completion.

## Main Users
- Student
- Supervisor
- Workshop Manager

## Main Goal
Help students plan, build, document, and manage hardware projects while allowing supervisors to monitor progress and workshop managers to manage workshop resources and attendance.

## Core Principles
- The platform is not a generic AI chatbot.
- AI features must support real project actions and structured project data.
- The Virtual Hardware Lab is 3D-based.
- The 3D Lab supports hardware placement, wiring, validation, and safety checks.
- The project does NOT include circuit simulation.
- The project does NOT execute Arduino code.
